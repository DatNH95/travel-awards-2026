# Bàn giao đăng ký 30Plus Travel

Mở `dang-ky-30-plus.html`. Bàn giao nguyên folder này: HTML, CSS, JS và các ảnh cần thiết đã nằm bên trong; không cần các folder khác của handoff-html.

- `css/30plus.css`: giao diện responsive.
- `js/`: form, kiểm tra điện thoại và Lucide icons (giữ thông tin giấy phép trong thư viện).
- `assets/`: ảnh nền và icon hình ảnh.

Các link điều hướng sang Homepage, Thể lệ, Tin tức và đăng ký Travel Awards trỏ đến domain demo `https://travel-awards-2026.vercel.app`; Tech đổi theo môi trường tích hợp. Form chỉ mô phỏng front-end, chưa gửi hồ sơ/email hoặc gọi backend. Bộ email bàn giao riêng trong `emails/email-30plus-travel/` của repo.
